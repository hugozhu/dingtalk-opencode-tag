# 行情数据推送基线跟踪

按 `docs/EVENT_HANDLING_POLICY.md`「数据推送：波动阈值告警」规则使用：
单次较上次变化 ≥5%、或 24h 累计 ≥10% → 立即告警；否则静默。

每日 ~09:59 收到 pi9-bookworm（树莓派群）资产推送后，把可解析出的数值追加到下表，
下一轮以此表为对比基准（避免再次出现「无基线 → 无法判阈值」的断档）。

**比价口径**：黄金统一用「国内 元/克」；BTC 统一用「美元/枚」。
推送里的「人民币万元/枚」常因隐含汇率不一致而失真（见 2026-09-13 备注），**不作为阈值判据**。

## 数据源质量记录

- 2026-09-13：首次记录「人民币折算口径自相矛盾」（同一推送 BTC $77,000 ↔ 55 万元，隐含汇率 7.14；前一日隐含 6.55）。按规范「数据源异常连续 3 次 → 提示数据源可能故障」起算，当前第 1 次，已在回复中提示用户，不单独告警。
- 2026-09-14：**第 2 次**。同一推送 BTC 51.55 万元 ↔ $72,000~77,000，隐含 USDCNY 跨 6.70~7.16（单条推送内部就差 6.9%）；相对 09-13 隐含 7.14 又降到 6.92。
  拆解验证：`550,000 × (1 - 3.25%) × (6.92 / 7.14) ≈ 515,700`，与推送的 515,500 几乎吻合 → 人民币口径的 -6.27% 中，约一半（-3.25%）是真实美元币价下跌，另一半（-3.09%）来自**推送自报汇率的日间跳变**。单日 USDCNY 变动 3% 不符合现实汇率波动幅度，判定为折算口径仍不可靠。
  结论：**阈值判定只认美元口径**（本次下沿 -6.49% 触发告警），人民币口径仅作展示。连续异常计数 2/3，下次（09-15）若再现即按「数据源可能故障」正式提示。
- 2026-09-15：**第 3 次 → 计数满 3/3，正式提示「数据源可能故障」**。本次推送内部只有一个币价对（523,000 元 ↔ $77,800），单条自洽（隐含 6.7224），但**日间跳变**依旧：对 09-14 隐含 6.92 变动 -2.86%，对 09-13 隐含 7.14 两日累计 -5.85%。真实 USDCNY 不可能单日波动 2.9%。
  交叉验证：`(1 + 4.43%) × (6.7224 / 6.92) - 1 = +1.44%`，与推送人民币口径的实际涨幅 +1.45% 吻合 → 再次证明「人民币数字 = 美元币价 × 一个每日漂移的自报汇率」，该汇率不可信。
  隐含汇率 4 日轨迹：6.72(09-11) → 6.55(09-12) → 7.14(09-13) → 6.92(09-14) → 6.72(09-15)，在 6.55~7.14 间无规律摆动（峰谷差 9%），**判定 pi9 侧汇率取数为随机源/缓存脏值**。
  处置：① 已在回复中正式提示用户数据源故障，请 pi9 侧改为固定汇率源或直接只推美元币价；② 在修复前，**阈值判定继续只认美元口径**，人民币口径仅作展示，不参与任何告警计算；③ 计数保持 3/3（故障未修复即持续提示，不清零）。
- 2026-09-16：**第 4 次，计数保持 3/3 不清零 → 第 2 次正式提示「数据源故障」**。本次拿到前三次都没有的**铁证：同一条推送内部两个标的的隐含汇率互不一致**。
  - 黄金侧：$4,310/oz ÷ 31.1035 = 138.57 USD/g；推送报 930~936 元/克 → 隐含 USDCNY **6.711~6.755**（中值 6.7332）。
  - BTC 侧：$77,800 ↔ 50.6~51.5 万元 → 隐含 USDCNY **6.504~6.619**（中值 6.5617）。
  - 同一时点、同一条消息，两个汇率中值差 **+2.61%**。前三次异常都只能靠「日间跳变」推断（理论上可归因于隔日基准取值差异），本次是**单条内部自相矛盾**，无法用日间波动解释 → 至少一处为脏值，判定 pi9 汇率取数不可信已无争议。
  - 反证：BTC 美元币价 09-15 → 09-16 **完全持平（$77,800）**，但人民币口径显示 -2.39% 的「下跌」。若该人民币数字可信，等于 USDCNY 单日贬值 2.39%；而同一推送黄金侧隐含汇率对 09-15 的 6.7224 只变动 +0.16%。两者对「今天的汇率」给出矛盾答案 → 人民币口径的 -2.39% 是**纯折算噪声，非行情**。
  - 隐含汇率 5 日轨迹：6.72(09-11) → 6.55(09-12) → 7.14(09-13) → 6.92(09-14) → 6.72(09-15) → 6.56(09-16)，峰谷差 **9.0%**，无规律摆动，继续支持「随机源/缓存脏值」判定。
